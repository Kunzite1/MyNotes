# FreeRTOS 函数定义

> 整理范围：本工程 `C8T6工程-写注释/FreeRTOS` 中的 FreeRTOS V9.0.0。  
> 标记说明：**宏**表示接口最终由宏展开；**配置**表示需要在 `FreeRTOSConfig.h` 中开启对应选项；`FromISR` 接口只能用于中断环境，且不能阻塞。

## 1. 命名与返回值约定

| 前缀    | 含义                      |
| ----- | ----------------------- |
| `v`   | 返回 `void`               |
| `x`   | 返回非标准基础类型、句柄或结构体类型      |
| `ux`  | 返回无符号基础类型 `UBaseType_t` |
| `ul`  | 返回 `uint32_t`           |
| `pv`  | 返回 `void *`             |
| `pc`  | 返回 `char *`             |
| `prv` | 源文件内部的 `static` 私有函数    |

常见返回值：`pdPASS/pdFAIL` 表示操作成功/失败，`pdTRUE/pdFALSE` 表示布尔结果；队列操作还常返回 `errQUEUE_FULL`、`errQUEUE_EMPTY`。时间参数均以 Tick 为单位，`pdMS_TO_TICKS(ms)` 可将毫秒换算为 Tick，`portMAX_DELAY` 表示最大等待时间。

## 2. 任务管理（`task.h`、`tasks.c`）

### 2.1 任务创建

```c
BaseType_t xTaskCreate(TaskFunction_t pxTaskCode,
                       const char * const pcName,
                       const uint16_t usStackDepth,
                       void * const pvParameters,
                       UBaseType_t uxPriority,
                       TaskHandle_t * const pxCreatedTask);
```

动态分配 TCB 和任务栈并创建任务。

| 参数              | 含义                                                  |
| --------------- | --------------------------------------------------- |
| `pxTaskCode`    | 任务入口函数，原型必须是 `void task(void *)`，通常不应返回             |
| `pcName`        | 调试用任务名，最多保存 `configMAX_TASK_NAME_LEN` 个字符（含结尾 `\0`） |
| `usStackDepth`  | 栈深度，注意：**单位是 `StackType_t`，不是字节**                   |
| `pvParameters`  | 传给任务入口的参数指针，调用者须保证所指对象生命周期足够长                       |
| `uxPriority`    | 初始优先级，范围为 `0` 到 `configMAX_PRIORITIES - 1`          |
| `pxCreatedTask` | 输出任务句柄；不需要时可传 `NULL`                                |

返回 `pdPASS` 表示成功，否则通常表示堆空间不足。

```c
TaskHandle_t xTaskCreateStatic(TaskFunction_t pxTaskCode,
                               const char * const pcName,
                               const uint32_t ulStackDepth,
                               void * const pvParameters,
                               UBaseType_t uxPriority,
                               StackType_t * const puxStackBuffer,
                               StaticTask_t * const pxTaskBuffer);
```

静态创建任务，由调用者提供栈和 TCB 缓冲区；需 `configSUPPORT_STATIC_ALLOCATION == 1`。成功返回句柄，失败返回 `NULL`。

```c
BaseType_t xTaskCreateRestricted(const TaskParameters_t * const pxTaskDefinition,
                                 TaskHandle_t *pxCreatedTask);
void vTaskAllocateMPURegions(TaskHandle_t xTask,
                             const MemoryRegion_t * const pxRegions);
```

MPU 端口使用：创建受限任务、重新配置任务可访问的内存区域。当前 STM32F103 Cortex-M3 工程未使用 MPU 包装层。

### 2.2 删除、延时与周期运行

| 原型                                                                                             | 作用                               | 配置条件                           |
| ---------------------------------------------------------------------------------------------- | -------------------------------- | ------------------------------ |
| `void vTaskDelete(TaskHandle_t xTaskToDelete)`                                                 | 删除指定任务；传 `NULL` 删除当前任务，内存由空闲任务回收 | `INCLUDE_vTaskDelete == 1`     |
| `void vTaskDelay(const TickType_t xTicksToDelay)`                                              | 当前任务相对延时；延时从调用时刻开始               | `INCLUDE_vTaskDelay == 1`      |
| `void vTaskDelayUntil(TickType_t * const pxPreviousWakeTime, const TickType_t xTimeIncrement)` | 绝对周期延时，适合固定频率任务                  | `INCLUDE_vTaskDelayUntil == 1` |
| `BaseType_t xTaskAbortDelay(TaskHandle_t xTask)`                                               | 让处于阻塞态的任务提前结束等待                  | `INCLUDE_xTaskAbortDelay == 1` |

`vTaskDelayUntil()` 会更新 `*pxPreviousWakeTime`。首次调用前应令其等于 `xTaskGetTickCount()`；与 `vTaskDelay()` 相比，它不会因任务自身执行时间而累积周期误差。

### 2.3 优先级与任务状态

| 原型                                                                                                                    | 作用                      |
| --------------------------------------------------------------------------------------------------------------------- | ----------------------- |
| `UBaseType_t uxTaskPriorityGet(TaskHandle_t xTask)`                                                                   | 获取任务当前优先级；`NULL` 表示当前任务 |
| `UBaseType_t uxTaskPriorityGetFromISR(TaskHandle_t xTask)`                                                            | 中断中获取优先级                |
| `void vTaskPrioritySet(TaskHandle_t xTask, UBaseType_t uxNewPriority)`                                                | 修改任务优先级                 |
| `eTaskState eTaskGetState(TaskHandle_t xTask)`                                                                        | 查询运行、就绪、阻塞、挂起或删除状态      |
| `void vTaskGetInfo(TaskHandle_t xTask, TaskStatus_t *pxTaskStatus, BaseType_t xGetFreeStackSpace, eTaskState eState)` | 获取指定任务的状态快照             |

以上接口分别受相应的 `INCLUDE_...` 配置控制。高优先级数值代表高优先级。

### 2.4 挂起与恢复

| 原型                                                          | 作用                   |
| ----------------------------------------------------------- | -------------------- |
| `void vTaskSuspend(TaskHandle_t xTaskToSuspend)`            | 挂起任务；`NULL` 表示当前任务   |
| `void vTaskResume(TaskHandle_t xTaskToResume)`              | 在任务上下文恢复任务           |
| `BaseType_t xTaskResumeFromISR(TaskHandle_t xTaskToResume)` | 在中断中恢复任务，并返回是否应切换上下文 |

均需 `INCLUDE_vTaskSuspend == 1`。恢复事件可能丢失时，应优先使用任务通知或信号量，而不是 `xTaskResumeFromISR()`。

### 2.5 调度器控制

| 原型/宏                                      | 作用                                               |
| ----------------------------------------- | ------------------------------------------------ |
| `void vTaskStartScheduler(void)`          | 创建空闲任务（以及定时器任务）并启动调度器                            |
| `void vTaskEndScheduler(void)`            | 结束调度器；多数裸机端口不实现实际返回                              |
| `void vTaskSuspendAll(void)`              | 挂起调度器，嵌套计数加一；不会关闭中断                              |
| `BaseType_t xTaskResumeAll(void)`         | 恢复调度器；返回恢复过程中是否已发生切换                             |
| `BaseType_t xTaskGetSchedulerState(void)` | 返回 `taskSCHEDULER_NOT_STARTED/RUNNING/SUSPENDED` |
| `taskYIELD()`                             | 主动让出 CPU，触发一次调度                                  |

调度器挂起期间不得调用可能阻塞的 API。它与临界区不同：中断仍可执行，只是就绪任务的切换被延后。

### 2.6 Tick、句柄与任务信息

| 原型                                                                                                                  | 作用                    |
| ------------------------------------------------------------------------------------------------------------------- | --------------------- |
| `TickType_t xTaskGetTickCount(void)`                                                                                | 获取系统 Tick 计数          |
| `TickType_t xTaskGetTickCountFromISR(void)`                                                                         | 在中断中获取 Tick 计数        |
| `UBaseType_t uxTaskGetNumberOfTasks(void)`                                                                          | 获取当前任务总数              |
| `TaskHandle_t xTaskGetCurrentTaskHandle(void)`                                                                      | 获取当前任务句柄              |
| `TaskHandle_t xTaskGetIdleTaskHandle(void)`                                                                         | 获取空闲任务句柄              |
| `TaskHandle_t xTaskGetHandle(const char *pcNameToQuery)`                                                            | 按名称查找任务；任务名应唯一        |
| `char *pcTaskGetName(TaskHandle_t xTaskToQuery)`                                                                    | 获取任务名                 |
| `UBaseType_t uxTaskGetStackHighWaterMark(TaskHandle_t xTask)`                                                       | 获取历史最小剩余栈深度；越接近 0 越危险 |
| `BaseType_t xTaskGetStaticBuffers(TaskHandle_t xTask, StackType_t **ppuxStackBuffer, StaticTask_t **ppxTaskBuffer)` | 取回静态任务缓冲区             |

### 2.7 统计与调试

| 原型                                                                                                | 作用          | 配置条件                            |
| ------------------------------------------------------------------------------------------------- | ----------- | ------------------------------- |
| `UBaseType_t uxTaskGetSystemState(TaskStatus_t *array, UBaseType_t size, uint32_t *totalRunTime)` | 取得全部任务快照    | `configUSE_TRACE_FACILITY == 1` |
| `void vTaskList(char *pcWriteBuffer)`                                                             | 生成人类可读任务状态表 | 同时开启格式化统计                       |
| `void vTaskGetRunTimeStats(char *pcWriteBuffer)`                                                  | 生成各任务运行时间比例 | 开启运行时间统计与格式化统计                  |
| `void vTaskSetTaskNumber(TaskHandle_t xTask, UBaseType_t number)`                                 | 设置跟踪编号      | 跟踪功能开启                          |
| `UBaseType_t uxTaskGetTaskNumber(TaskHandle_t xTask)`                                             | 获取跟踪编号      | 跟踪功能开启                          |

格式化函数内部使用 `sprintf()`，会占用较多栈和代码空间；资源紧张时应直接使用 `uxTaskGetSystemState()`。

### 2.8 任务通知

每个任务自带一个 32 位通知值，适合一对一事件、轻量计数信号量或事件位。需 `configUSE_TASK_NOTIFICATIONS == 1`。

```c
BaseType_t xTaskGenericNotify(TaskHandle_t xTaskToNotify,
                              uint32_t ulValue,
                              eNotifyAction eAction,
                              uint32_t *pulPreviousNotificationValue);

BaseType_t xTaskGenericNotifyFromISR(TaskHandle_t xTaskToNotify,
                                     uint32_t ulValue,
                                     eNotifyAction eAction,
                                     uint32_t *pulPreviousNotificationValue,
                                     BaseType_t *pxHigherPriorityTaskWoken);
```

常用宏：

| 宏                                                | 对应语义                    |
| ------------------------------------------------ | ----------------------- |
| `xTaskNotify()` / `xTaskNotifyFromISR()`         | 按 `eNotifyAction` 更新通知值 |
| `xTaskNotifyGive()` / `vTaskNotifyGiveFromISR()` | 通知值加一，适合作为轻量计数信号量       |
| `xTaskNotifyAndQuery()`                          | 更新并返回原通知值               |

接收接口：

| 原型                                                                                                          | 作用                 |
| ----------------------------------------------------------------------------------------------------------- | ------------------ |
| `BaseType_t xTaskNotifyWait(uint32_t clearOnEntry, uint32_t clearOnExit, uint32_t *value, TickType_t wait)` | 等待通知，可在进入和退出时清除指定位 |
| `uint32_t ulTaskNotifyTake(BaseType_t clearCountOnExit, TickType_t wait)`                                   | 等待通知计数；清零或减一后返回原值  |
| `BaseType_t xTaskNotifyStateClear(TaskHandle_t xTask)`                                                      | 清除“通知待处理”状态，不修改通知值 |

### 2.9 应用钩子与线程本地存储

| 原型                                                                                             | 作用       |
| ---------------------------------------------------------------------------------------------- | -------- |
| `void vTaskSetApplicationTaskTag(TaskHandle_t xTask, TaskHookFunction_t pxHookFunction)`       | 设置任务钩子   |
| `TaskHookFunction_t xTaskGetApplicationTaskTag(TaskHandle_t xTask)`                            | 获取任务钩子   |
| `BaseType_t xTaskCallApplicationTaskHook(TaskHandle_t xTask, void *pvParameter)`               | 调用任务钩子   |
| `void vTaskSetThreadLocalStoragePointer(TaskHandle_t xTask, BaseType_t xIndex, void *pvValue)` | 设置线程本地指针 |
| `void *pvTaskGetThreadLocalStoragePointer(TaskHandle_t xTask, BaseType_t xIndex)`              | 获取线程本地指针 |

分别依赖 `configUSE_APPLICATION_TASK_TAG` 和 `configNUM_THREAD_LOCAL_STORAGE_POINTERS`。

### 2.10 内核内部任务函数

这些函数供队列、事件组、移植层调用，应用代码通常不直接使用：

| 函数                                                                                     | 内核作用                          |
| -------------------------------------------------------------------------------------- | ----------------------------- |
| `xTaskIncrementTick()`                                                                 | Tick 加一、处理超时任务并判断是否需要切换       |
| `vTaskSwitchContext()`                                                                 | 选择最高优先级就绪任务并更新 `pxCurrentTCB` |
| `vTaskPlaceOnEventList()` / `vTaskPlaceOnUnorderedEventList()`                         | 将当前任务挂入对象事件等待链表               |
| `xTaskRemoveFromEventList()` / `vTaskRemoveFromUnorderedEventList()`                   | 事件发生后解除一个等待任务                 |
| `vTaskSetTimeOutState()` / `xTaskCheckForTimeOut()`                                    | 记录并检查跨 Tick 溢出的等待超时           |
| `vTaskMissedYield()`                                                                   | 记录调度器恢复后需要补做切换                |
| `vTaskStepTick()` / `eTaskConfirmSleepModeStatus()`                                    | Tickless Idle 支持              |
| `pvTaskIncrementMutexHeldCount()`、`xTaskPriorityInherit()`、`xTaskPriorityDisinherit()` | 互斥量优先级继承与恢复                   |

## 3. 队列（`queue.h`、`queue.c`）

队列按值复制数据。创建时必须指定元素个数和每个元素的字节数。

### 3.1 创建、复位与删除

| 原型/宏                                                                                                                                       | 作用             |
| ------------------------------------------------------------------------------------------------------------------------------------------ | -------------- |
| `xQueueCreate(uxQueueLength, uxItemSize)`                                                                                                  | **宏**，动态创建普通队列 |
| `xQueueCreateStatic(uxQueueLength, uxItemSize, pucStorage, pxStaticQueue)`                                                                 | **宏**，静态创建队列   |
| `QueueHandle_t xQueueGenericCreate(UBaseType_t length, UBaseType_t itemSize, uint8_t type)`                                                | 通用动态创建实现       |
| `QueueHandle_t xQueueGenericCreateStatic(UBaseType_t length, UBaseType_t itemSize, uint8_t *storage, StaticQueue_t *buffer, uint8_t type)` | 通用静态创建实现       |
| `xQueueReset(xQueue)`                                                                                                                      | **宏**，清空已有队列   |
| `void vQueueDelete(QueueHandle_t xQueue)`                                                                                                  | 删除队列并释放动态内存    |

### 3.2 任务上下文收发

```c
BaseType_t xQueueGenericSend(QueueHandle_t xQueue,
                             const void * const pvItemToQueue,
                             TickType_t xTicksToWait,
                             const BaseType_t xCopyPosition);

BaseType_t xQueueGenericReceive(QueueHandle_t xQueue,
                                void * const pvBuffer,
                                TickType_t xTicksToWait,
                                const BaseType_t xJustPeeking);
```

| 常用宏                                   | 作用               |
| ------------------------------------- | ---------------- |
| `xQueueSend()` / `xQueueSendToBack()` | 复制到队尾            |
| `xQueueSendToFront()`                 | 复制到队首            |
| `xQueueOverwrite()`                   | 覆盖写，仅适合长度为 1 的队列 |
| `xQueueReceive()`                     | 读出并移除队首元素        |
| `xQueuePeek()`                        | 读出但不移除队首元素       |

`xTicksToWait` 仅在队列满（发送）或空（接收）时生效；调度器启动前必须传 0。

### 3.3 中断上下文收发

| 原型/宏                                                                   | 作用             |
| ---------------------------------------------------------------------- | -------------- |
| `xQueueSendFromISR()` / `xQueueSendToBackFromISR()`                    | 中断中写到队尾        |
| `xQueueSendToFrontFromISR()`                                           | 中断中写到队首        |
| `xQueueOverwriteFromISR()`                                             | 中断中覆盖长度为 1 的队列 |
| `BaseType_t xQueueGenericSendFromISR(...)`                             | 上述发送宏的通用实现     |
| `BaseType_t xQueueReceiveFromISR(QueueHandle_t, void *, BaseType_t *)` | 中断中接收          |
| `BaseType_t xQueuePeekFromISR(QueueHandle_t, void *)`                  | 中断中查看但不移除      |
| `BaseType_t xQueueGiveFromISR(QueueHandle_t, BaseType_t *)`            | 中断中释放信号量的专用实现  |

`pxHigherPriorityTaskWoken` 调用前应初始化为 `pdFALSE`；返回后若为 `pdTRUE`，在 ISR 退出前调用 `portYIELD_FROM_ISR()`。

### 3.4 状态查询

| 原型/宏                                                                    | 作用               |
| ----------------------------------------------------------------------- | ---------------- |
| `UBaseType_t uxQueueMessagesWaiting(const QueueHandle_t xQueue)`        | 当前元素数            |
| `UBaseType_t uxQueueSpacesAvailable(const QueueHandle_t xQueue)`        | 当前空闲槽数           |
| `UBaseType_t uxQueueMessagesWaitingFromISR(const QueueHandle_t xQueue)` | 中断中查询元素数         |
| `xQueueIsQueueEmptyFromISR()` / `xQueueIsQueueFullFromISR()`            | 中断中检查空/满，主要供内核使用 |

### 3.5 队列集与注册表

队列集需 `configUSE_QUEUE_SETS == 1`：

| 原型                                                                                    | 作用         |
| ------------------------------------------------------------------------------------- | ---------- |
| `QueueSetHandle_t xQueueCreateSet(UBaseType_t uxEventQueueLength)`                    | 创建队列集      |
| `BaseType_t xQueueAddToSet(QueueSetMemberHandle_t member, QueueSetHandle_t set)`      | 添加队列或信号量   |
| `BaseType_t xQueueRemoveFromSet(QueueSetMemberHandle_t member, QueueSetHandle_t set)` | 移除成员       |
| `QueueSetMemberHandle_t xQueueSelectFromSet(QueueSetHandle_t set, TickType_t wait)`   | 等待并返回已就绪成员 |
| `QueueSetMemberHandle_t xQueueSelectFromSetFromISR(QueueSetHandle_t set)`             | 中断中选择就绪成员  |

调试注册表接口：`vQueueAddToRegistry()`、`vQueueUnregisterQueue()`、`pcQueueGetName()`；仅用于让内核感知调试器显示名称，不改变队列行为。

## 4. 信号量与互斥量（`semphr.h`）

信号量和互斥量底层都复用队列，接口多数是宏。

### 4.1 创建

| 宏/原型                                                          | 作用              | 条件                                   |
| ------------------------------------------------------------- | --------------- | ------------------------------------ |
| `xSemaphoreCreateBinary()` / `xSemaphoreCreateBinaryStatic()` | 创建二值信号量，初始为空    | 动态/静态分配                              |
| `vSemaphoreCreateBinary(xSemaphore)`                          | 旧式宏，创建后初始为“已给出” | 不推荐新代码使用                             |
| `xSemaphoreCreateCounting(max, initial)`                      | 创建计数信号量         | `configUSE_COUNTING_SEMAPHORES == 1` |
| `xSemaphoreCreateMutex()` / `xSemaphoreCreateMutexStatic()`   | 创建普通互斥量         | `configUSE_MUTEXES == 1`             |
| `xSemaphoreCreateRecursiveMutex()` / `...Static()`            | 创建递归互斥量         | 同时开启递归互斥量                            |

### 4.2 获取、释放与查询

| 宏                                                         | 作用                        |
| --------------------------------------------------------- | ------------------------- |
| `xSemaphoreTake(xSemaphore, xTicksToWait)`                | 获取二值/计数信号量或互斥量            |
| `xSemaphoreGive(xSemaphore)`                              | 释放；互斥量必须由持有者释放            |
| `xSemaphoreTakeFromISR()` / `xSemaphoreGiveFromISR()`     | ISR 中操作信号量；互斥量不能在 ISR 使用  |
| `xSemaphoreTakeRecursive()` / `xSemaphoreGiveRecursive()` | 递归获取/释放，次数必须配对            |
| `uxSemaphoreGetCount(xSemaphore)`                         | 获取当前计数；互斥量/二值信号量结果为 0 或 1 |
| `xSemaphoreGetMutexHolder(xMutex)`                        | 获取互斥量持有任务；仅适合调试           |
| `vSemaphoreDelete(xSemaphore)`                            | 删除底层队列对象                  |

互斥量带优先级继承且有所有权；二值信号量没有所有权，更适合任务同步和 ISR 到任务的通知。

## 5. 事件组（`event_groups.h`、`event_groups.c`）

```c
EventBits_t xEventGroupWaitBits(EventGroupHandle_t xEventGroup,
                                const EventBits_t uxBitsToWaitFor,
                                const BaseType_t xClearOnExit,
                                const BaseType_t xWaitForAllBits,
                                TickType_t xTicksToWait);
```

等待任意位或全部位。返回值是退出等待前的事件位快照；超时后调用者应自行判断目标位是否满足。

| 原型/宏                                                                                                                       | 作用                      |
| -------------------------------------------------------------------------------------------------------------------------- | ----------------------- |
| `EventGroupHandle_t xEventGroupCreate(void)`                                                                               | 动态创建事件组                 |
| `EventGroupHandle_t xEventGroupCreateStatic(StaticEventGroup_t *buffer)`                                                   | 静态创建事件组                 |
| `EventBits_t xEventGroupSetBits(EventGroupHandle_t group, EventBits_t bits)`                                               | 设置事件位，并唤醒满足条件的任务        |
| `EventBits_t xEventGroupClearBits(EventGroupHandle_t group, EventBits_t bits)`                                             | 清除事件位，返回清除前的值           |
| `xEventGroupGetBits(group)`                                                                                                | **宏**，读取当前事件位           |
| `EventBits_t xEventGroupSync(EventGroupHandle_t group, EventBits_t bitsToSet, EventBits_t bitsToWaitFor, TickType_t wait)` | 设置自己的到达位并等待所有参与位，用作屏障同步 |
| `void vEventGroupDelete(EventGroupHandle_t group)`                                                                         | 删除事件组并解除所有等待任务          |
| `xEventGroupSetBitsFromISR()` / `xEventGroupClearBitsFromISR()`                                                            | ISR 延迟操作，通过定时器守护任务执行    |
| `EventBits_t xEventGroupGetBitsFromISR(EventGroupHandle_t group)`                                                          | ISR 中直接读取事件位            |

本工程为 32 位 Tick，事件组高 8 位供内核控制，用户可用位为 bit 0～23。

## 6. 软件定时器（`timers.h`、`timers.c`）

需 `configUSE_TIMERS == 1`。回调运行在定时器守护任务中，不能执行长时间操作或无限阻塞。

```c
TimerHandle_t xTimerCreate(const char * const pcTimerName,
                           TickType_t xTimerPeriodInTicks,
                           UBaseType_t uxAutoReload,
                           void * const pvTimerID,
                           TimerCallbackFunction_t pxCallbackFunction);
```

`xTimerCreateStatic()` 参数相同，末尾增加 `StaticTimer_t *pxTimerBuffer`。

| 宏/原型                                                                                             | 作用           |
| ------------------------------------------------------------------------------------------------ | ------------ |
| `xTimerStart()` / `xTimerStartFromISR()`                                                         | 启动定时器        |
| `xTimerStop()` / `xTimerStopFromISR()`                                                           | 停止定时器        |
| `xTimerReset()` / `xTimerResetFromISR()`                                                         | 从当前时刻重新计时    |
| `xTimerChangePeriod()` / `...FromISR()`                                                          | 修改周期并启动/重装   |
| `xTimerDelete()`                                                                                 | 删除定时器        |
| `BaseType_t xTimerIsTimerActive(TimerHandle_t xTimer)`                                           | 查询是否在活动链表中   |
| `void *pvTimerGetTimerID(TimerHandle_t xTimer)`                                                  | 获取用户 ID      |
| `void vTimerSetTimerID(TimerHandle_t xTimer, void *pvNewID)`                                     | 修改用户 ID      |
| `const char *pcTimerGetName(TimerHandle_t xTimer)`                                               | 获取调试名称       |
| `TickType_t xTimerGetPeriod(TimerHandle_t xTimer)`                                               | 获取周期         |
| `TickType_t xTimerGetExpiryTime(TimerHandle_t xTimer)`                                           | 获取预计到期 Tick  |
| `TaskHandle_t xTimerGetTimerDaemonTaskHandle(void)`                                              | 获取守护任务句柄     |
| `BaseType_t xTimerPendFunctionCall(PendedFunction_t fn, void *p1, uint32_t p2, TickType_t wait)` | 请求守护任务执行普通回调 |
| `BaseType_t xTimerPendFunctionCallFromISR(...)`                                                  | ISR 版本       |

所有控制宏最终调用 `xTimerGenericCommand()`，只是命令编号和参数不同。命令进入定时器命令队列后才真正生效。

## 7. 内核链表（`list.h`、`list.c`）

| 原型                                                                             | 作用                      |
| ------------------------------------------------------------------------------ | ----------------------- |
| `void vListInitialise(List_t * const pxList)`                                  | 初始化空链表和尾部哨兵             |
| `void vListInitialiseItem(ListItem_t * const pxItem)`                          | 初始化节点，使其不属于任何链表         |

## 8. 协程（`croutine.h`、`croutine.c`）

需 `configUSE_CO_ROUTINES == 1`。协程是早期为极小 RAM 设备设计的协作式机制，新项目通常优先使用任务。

| 原型/宏                                                                                          | 作用            |
| --------------------------------------------------------------------------------------------- | ------------- |
| `BaseType_t xCoRoutineCreate(crCOROUTINE_CODE code, UBaseType_t priority, UBaseType_t index)` | 创建协程          |
| `void vCoRoutineSchedule(void)`                                                               | 执行一次最高优先级就绪协程 |
| `crSTART()` / `crEND()`                                                                       | 协程函数开始/结束框架   |
| `crDELAY()`                                                                                   | 协程延时          |
| `crQUEUE_SEND()` / `crQUEUE_RECEIVE()`                                                        | 协程上下文操作队列     |
| `crQUEUE_SEND_FROM_ISR()` / `crQUEUE_RECEIVE_FROM_ISR()`                                      | ISR 与协程队列通信   |
| `vCoRoutineAddToDelayedList()` / `xCoRoutineRemoveFromEventList()`                            | 协程内核阻塞/解除阻塞   |

协程跨阻塞点需要保留的局部变量必须声明为 `static`。

## 9. 内存管理（`portable.h`、`heap_*.c`）

| 原型                                                         | 作用                           |
| ---------------------------------------------------------- | ---------------------------- |
| `void *pvPortMalloc(size_t xSize)`                         | 从 FreeRTOS 堆分配内存             |
| `void vPortFree(void *pv)`                                 | 释放内存；`heap_1` 不支持实际释放        |
| `size_t xPortGetFreeHeapSize(void)`                        | 当前剩余堆空间                      |
| `size_t xPortGetMinimumEverFreeHeapSize(void)`             | 历史最小剩余堆空间，仅部分 heap 实现提供      |
| `void vPortInitialiseBlocks(void)`                         | 重置/初始化堆实现；含义依 heap 方案而异      |
| `void vPortDefineHeapRegions(const HeapRegion_t *regions)` | 为 `heap_5` 定义多个不连续堆区，首次分配前调用 |

五种实现：`heap_1` 只分配不释放；`heap_2` 可释放但不合并相邻块；`heap_3` 包装标准库 `malloc/free`；`heap_4` 可释放并合并相邻块；`heap_5` 相当于支持多内存区的 `heap_4`。工程应只编译其中一个。

## 10. Cortex-M3 移植层（`portable/RVDS/ARM_CM3`）

| 原型/入口                                                       | 作用                                 |
| ----------------------------------------------------------- | ---------------------------------- |
| `StackType_t *pxPortInitialiseStack(...)`                   | 构造任务初始异常栈帧                         |
| `BaseType_t xPortStartScheduler(void)`                      | 配置 PendSV/SysTick 优先级和 Tick，启动首任务  |
| `void vPortEndScheduler(void)`                              | 结束调度器；Cortex-M3 裸机端口通常仅断言          |
| `void vPortEnterCritical(void)` / `vPortExitCritical(void)` | 管理临界区嵌套和中断屏蔽                       |
| `void vPortSetupTimerInterrupt(void)`                       | 配置 SysTick 周期中断                    |
| `void xPortSysTickHandler(void)`                            | Tick ISR，调用 `xTaskIncrementTick()` |
| `void xPortPendSVHandler(void)`                             | 保存当前任务上下文并恢复下一任务上下文                |
| `void vPortSVCHandler(void)`                                | SVC 启动第一个任务                        |

应用 ISR 若调用 FreeRTOS `FromISR` API，其中断优先级必须满足 `configMAX_SYSCALL_INTERRUPT_PRIORITY` 的约束。
